# Algoritmos fundamentais com testes unitários (Entregável 4)

> 📦 **Repositório arquivado.** A versão mais completa deste projeto, com 25 testes, programa interativo e versão em Java, está em **[testes-jest-algoritmos](https://github.com/Eujorgyn/testes-jest-algoritmos)**.

Esta versão tem seis algoritmos em JavaScript (primo, somatório, Fibonacci, MDC, Quicksort e contagem) com programação defensiva e **18 testes unitários em Jest**, três por algoritmo.

## Como executar

```bash
npm install
npm test
```

Mais detalhes sobre as regras adotadas estão no arquivo [Leia-me.md](Leia-me.md).
